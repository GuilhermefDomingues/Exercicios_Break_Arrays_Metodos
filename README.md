# Exercícios de Break, Arrays e Métodos em Java

Este repositório reúne minhas resoluções dos exercícios da apostila Break, Arrays e Métodos.

## Conteúdos praticados

- `break` para interromper laços de repetição
- Criação de arrays e acesso aos elementos por índice
- Percurso de arrays com laços de repetição
- Criação e chamada de métodos com parâmetros e retorno

## Como executar

1. No GitHub, clique em **Code → Download ZIP** e extraia os arquivos.
2. Abra a pasta do projeto no IntelliJ IDEA.
3. Abra a classe do exercício que deseja testar e clique em **Run** ao lado do método `main`.
